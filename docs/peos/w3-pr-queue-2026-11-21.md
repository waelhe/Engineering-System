## Repeatable live capture

The checked-in JSON is a dated snapshot, not an automatic background sync. To capture a new source-bound queue using GitHub's read-only REST API:

    GITHUB_TOKEN=... python tools/capture_w3_pr_queue.py

The command defaults to stdout and never changes GitHub state. Review its output, then explicitly write a refreshed snapshot with:

    GITHUB_TOKEN=... python tools/capture_w3_pr_queue.py --write

To compare a newly fetched snapshot with the checked-in file without modifying it:

    GITHUB_TOKEN=... python tools/capture_w3_pr_queue.py --check

The token needs only read access to the configured repository's metadata, contents and pull requests. The capture fails closed if governed PRs #787, #806–#811 or #837 disappear, if the default branch is no longer `main`, if #837 changes base branch, or if its base is not a verified ancestor of the current #787 head. New PRs are recorded as `unclassified` / `not_authorized_pending_adjudication`; no new PR is automatically approved or merge-authorized.
