# EGM Engineering System

This system extends EGM into a single engineering lifecycle:

1. Classify the task and discover the applicable project context.
2. Retrieve source-linked knowledge progressively.
3. Explore and design with Elephant.
4. Challenge the design with genuinely independent Goldfish reviewers.
5. Implement an approved plan within a declared write boundary.
6. Verify behavior against the exact tested revision and required environment.
7. Convert confirmed outcomes into governed knowledge, rules and controls.

The knowledge model distinguishes Signals, Evidence, Findings, Cases, Patterns, Decisions, Rules, Controls, Actions, Risk Acceptances and Verifications. These are related records in one store, not separate tools.

A signal is not a defect. A repeated symptom is not proof of a common cause. A rule without an active control is unenforced. A control without passing evidence is unproven. A fix commit alone does not prove closure.

Use the configured system repository as the source of canonical policies, schemas, CLI tools and knowledge. If it is unavailable in the current harness, state which operation is blocked instead of simulating it.
